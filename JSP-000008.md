## 3. Interactive Visual Verification Engine (`JSP-000008.html`)

A web-based frontend application that dynamically renders and validates the additive space structural equilibrium and algebraic invariants proved in Lean 4.

### 3.1 Control Panel & Parameter Specifications

* **`2n` (Max Even)**: The upper limit of the target even number (Default: `2000`, Range: `20 ~ 20000`). Automatically rounded to an even integer.
* **`Y Scale`**: Vertical axis scaling control (Default: `300`, Range: `10 ~ 100000`).
* **`Diff` (Difference Mode)**: Fixed difference between odd pairs (`All`, `0`, `2`, `4`, `6`, ..., `20`). `0` calculates standard Goldbach pairs ($k + m = 2n$).
* **`C-Filter` (Dynamic Composite Lattice Filter)**:
  * **`3 only (C3)`**: Isolates $3$-multiple composite lattices to inspect the primary backbone frame (period 6).
  * **`3, 5 (C3, C5)`**: Layers $3$- and $5$-multiple composite lattices (period 30) to observe initial interference patterns.
  * **`3, 5, 7 (C3..C7)`**: Includes $3$-, $5$-, and $7$-multiple lattices (period 210) to observe refined Moiré synchronization oscillations.
  * **`All Composites`**: Complete mode including all composite numbers.
* **`Mode` (Addition/Subtraction Mode)**:
  * `add`: Goldbach addition mode ($2n = \text{Odd}_2 + \text{Odd}_1$, range: $6 \sim 4n-6$).
  * `sub`: Odd difference mode ($\text{Even} = |\text{Odd}_2 - \text{Odd}_1|$, range: $0 \sim 2n-6$).
* **`Items` (Display Toggle)**:
  * `all3`: Displays $C_p$ (Composite pairs), $P_p$ (Prime pairs), and $M_p$ (Mixed pairs) simultaneously.
  * Individual modes: `hpmp`, `cp`, `pp`, `mp`.

### 3.2 User Manual & Verification Workflow

1. Open `JSP-000008.html` in standard modern web browsers (Chrome, Firefox, Edge, Safari, etc.).
